# ppt_system 目录说明

`ppt_system` 现按职责拆分为以下子包：

- `generation/`：内容规划、设计语法、页面评估、文字布局、原稿图与元素图 prompt 生成。
- `export/`：PPT 导出主链路、逐页脚本生成、脚本运行时、分层导出与恢复点管理。
- `image/`：图像处理、前景抠图、透明化、组件聚合、占位框识别、元素切分与对齐。
- `integrations/`：模型配置、OpenAI Provider、接口 URL、重试策略、响应解析。
- `jobs/`：任务状态、任务存储、目标路径、并发阶段控制。
- `runtime/`：日志、环境加载、控制台编码等运行时支撑能力。

兼容策略：

- 新增代码优先直接引用子包路径，例如 `ppt_system.export.export_pipeline`。

迁移建议：

1. 新功能直接落在对应子包，不再继续向根目录堆积实现。
2. 仓内导入已统一迁移到子包路径，外部调用也应同步完成迁移。
3. 根目录兼容模块已移除，后续请避免恢复旧路径引用。
