# 视觉定调与反馈修订（按需读取）

仅在用户难以选择风格、提出视觉修改，或明确要求收藏风格时读取对应部分。各页版式继续按内容由设计语法分配，本文件只约束视觉语言，不提供固定模板。

## 四维风格速选

四个维度可独立组合。场景只用于推荐，用户指定的视觉方向优先。

| 维度 | 可选方向与表达 |
| --- | --- |
| 信息密度 | 阅读型：论点与证据自洽、分组清楚，可独立传阅；演讲型：每页一个焦点、大字、充足留白，细节移至后续页或讲稿 |
| 基底明暗 | 纯净浅底：白／浅冷灰；温暖纸感：米白／浅燕麦；聚焦深底：深炭灰／深海蓝 |
| 视觉质感 | 扁平细线：纯色、细线图标；轻质感：用轻微明暗区分层次；编辑感：明显字号层级、细分割线。容器仅用于有意义的分组 |
| 色彩 | 通常一个主色、最多一个强调色，配合底色和中性色正文；图表的分类色按数据语义另定，整套保持一致 |

默认减少无语义的光晕、粒子、装饰渐变与悬浮 3D。留白随信息密度调整，文字置于清晰区域；用户明确要求的视觉效果予以保留。

工作汇报可用结论标题突出进展与动作；产品方案按痛点、方案、价值组织；创意展示突出单一主视觉；课题组会用论断与证据组织并留出处。它们均可搭配任意视觉组合。

把基底、配色、标题与图标气质写入现有 `style_guide.style_core` 对应字段；信息密度及逐页层级写入 `visual_brief`，不新增项目字段。修改后重新运行 `validate` 与 `prompts`。精确图表、数值、单位和引用按原文核实，并沿用现有原生图表与文字层流程。

## 模糊反馈到设计指令

先对照当前图定位原因，再选择适用修正；同一句反馈可能对应不同问题，不能机械套用整行。局部问题只改对应页，全局风格只在用户要求的范围内调整。

| 用户反馈 | 核查原因 | 可执行修正 |
| --- | --- | --- |
| 太花／AI 味重／像海报 | 装饰、光效或多色争抢注意力 | 删除无语义装饰，改为干净底色，收拢强调色，保留承担内容的图示 |
| 土／像老式模板 | 饱和度、装饰边框或层级不协调 | 降低不必要的饱和度，简化边框，统一对齐与间距，保持已认可主色 |
| 死板／像 Word | 连续列表、缺少分组和层级 | 按论点、流程或对比分区，突出核心数字或关键词；只在有助理解时用图标 |
| 太挤／喘不过气 | 信息量过载或间距太小 | 先扩大间距、整理语义分组；仍超载时提出拆页或压缩措辞，保留全部事实、数字、日期和业务原词，页数变化须经用户同意 |
| 没重点 | 所有区块权重相同 | 指定一个核心结论，用字号、字重或主色强调；辅助信息降低视觉权重 |
| 太暗／投影看不清 | 明度与文字对比不足 | 优先提高文字与底色对比；用户要求浅底时再切换底色，并同步调整图示颜色 |
| 太素／缺少设计感 | 视觉层级弱或构图平均 | 拉开字号层级，按内容重排主次；必要时引入一个相关主视觉或非对称分区 |
| 不严谨／太随意 | 图示语言或装饰与场景不符 | 统一对齐、线宽和圆角，将不合适的卡通装饰换成准确结构图，保留已认可色板 |
| 字太乱／费劲 | 细碎标签、文字区分散 | 将说明整理到清晰文字区，统一层级与对齐；准确原文继续由可编辑文字层承载，不删除必要信息 |

## 局部修改防跑偏

将上一版样板图作为实际图像输入，明确列出保留项与修改项。若问题就在布局或色板，不得同时要求将它们完全锁定。

```text
[KEEP STRICTLY]
保留：<用户认可的构图、配色、图标等具体项>。
逐字保留：<已核实的标题、事实、数字、日期与业务原词>。
[MODIFY ONLY]
只修改：<本轮明确的问题及可观察的目标，通常一到三项>。
其他视觉属性保持与参考图一致。
```

一次只重生成目标页并展示。连续两轮仍未收敛时，暂停生图，给出两个简短且差异明确的文字方向，等用户选定后再继续。已经免确认的任务可选用最符合原要求的方向，并在下一次交付时说明取舍。

## 常用风格收藏

只在用户明确要求收藏时保存，不自动把单次审美偏好变为全局要求。默认写入工作区 `user-styles.md`；用户指定个人跨项目收藏时才写入 `<SKILL_DIR>/references/user-styles.md`。不预建空文件。

先把确认图保存到持久目录，禁止记录临时工具路径。相对样板路径以收藏文件所在目录为基准；复用前确认可访问，并将图像实际传入生图调用。工作区与个人收藏同名时，使用工作区版本。

```markdown
### <风格名>
- 适用场景：<内容组织偏好>
- 视觉基因：<阅读型或演讲型 | 基底明暗 | 视觉质感 | 主色与强调色>
- 样板参考图：<持久绝对路径或相对收藏文件的路径>
```

复用只继承视觉语言，重新规划新材料的内容和逐页版式。文字风格描述可保留，但缺失的样板图不能充当已确认视觉参考，应回到单页试妆流程。
