# 复杂图表与可编辑数据

本流程适用于柱线组合图、次坐标轴，以及用 `@oai/artifact-tool` 制作的图表。使用工作区随附的 Node.js 运行库，按 presentations Skill 的本地实现说明和图表 API 创建原生图表。最终文件可直接交给本 Skill 的 `preview`，无需建立 `project.json`。

1. **制备原生草稿。** 从可核实的数据录入分类、系列、原始值、单位和数字格式。用 `slide.charts.add(...)` 创建图表并导出草稿 PPTX。制作柱线组合图时，可先用柱形图放入所有系列，导出后再将指定系列改成折线。比率按实际比例录入，例如 73% 录入 `0.73`，轴和标签用 `0%` 格式。
2. **按关系定位图表。** 沿幻灯片的图表关系找到 OOXML 图表部件。部件路径取决于导出器。以 XML 节点和关系 ID 修改草稿副本，保留图表在幻灯片上的位置、原有样式和其他内容。
3. **按需补组合图与次轴。** 在同一 `c:plotArea` 中保留柱形图组，把折线系列移入 `c:lineChart`。保留各系列唯一的 `c:idx`、`c:order`、名称和数据引用。移除仅属于柱形系列的子节点，按折线系列的结构保留或设置线条和标记。为折线组设置独立轴 ID，引入互相引用的次分类轴和右侧次值轴。隐藏重复的次分类轴，核对主次分类轴的分类顺序、位置和交叉设置。主轴和次轴分别按各自的单位设定范围与格式。
4. **为每张图表挂接 Excel 数据。** 先检查导出的图表是否已经连接内嵌工作簿。数据完整时保留该工作簿。缺少时，为每张图表生成独立的 `.xlsx`，首列放分类，其余列按系列填数，表头使用系列名。将工作簿放入 PPTX 的嵌入部件，并在图表部件的关系文件中添加指向它的内部 `package` 关系。用图表的 `c:externalData/@r:id` 引用该关系，同时注册 `.xlsx` 的内容类型。将仅含字面量的系列名、分类和值改为指向工作表范围的 `c:strRef` 或 `c:numRef`，并保留与表格一致的缓存。组合后的柱形和折线系列共享同一张工作簿，分别引用各自的数据列。
5. **在最终文件中验收。** 逐张核对图表、工作簿关系与数据范围，确认每个系列都引用内嵌工作簿中的正确数据。用本机 PowerPoint 打开最终 PPTX，确认无修复提示，并验证每张原生图表可以使用「编辑数据」。对组合图，在验收副本中修改一个折线值，检查折线与原生标签随数据更新。用下列命令渲染交付文件，再检查次轴单位、分类位置、标签裁切和数据遮挡。

```text
python scripts/deck_cli.py preview --pptx result.pptx --output-dir previews
```
