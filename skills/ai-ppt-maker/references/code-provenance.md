# 随包代码来源

`scripts/ppt_system/` 中的事实锚点、设计语法、图像处理、PowerPoint 渲染和导出模块，来自原 AI PPT Maker 项目同名 `ppt_system/` 模块的 UTF-8 副本。图片版导出函数在副本中增加了可配置的幻灯片宽度。`scripts/asset_assembly.py` 来自原项目的 `tools/assemble_assets_only_ppt.py`。独立编排入口在 `scripts/deck_cli.py` 与 `scripts/skill_core/`。

发布或再分发时保留 Skill 根目录的 `LICENSE`。该许可证为原项目的非商业使用许可；复制源码没有改变其许可条件。
