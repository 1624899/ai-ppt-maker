# 随包代码来源

`scripts/ppt_system/` 中的事实锚点、设计语法、图像处理、PowerPoint 渲染和导出模块，来自原 AI PPT Maker 项目同名 `ppt_system/` 模块的 UTF-8 副本。Skill 副本包含独立导出、文字样式估算和 PowerPoint 渲染探测所需的调整。`scripts/asset_assembly.py` 来自原项目的 `tools/assemble_assets_only_ppt.py`。独立编排入口在 `scripts/deck_cli.py` 与 `scripts/skill_core/`。

发布或再分发时保留 Skill 根目录的 `LICENSE`。该许可证为原项目的非商业使用许可；复制源码没有改变其许可条件。

`assets/icons/lucide/` 的 SVG 与英文关键词来自官方 npm 包 `lucide-static@1.78.0`。`catalog.json` 记录来源、版本及 npm 包完整性摘要。图标使用独立的 ISC / MIT 许可，完整声明保存在该目录的 `LICENSE`，再分发这些素材时一并保留。`assets/icons/aliases.zh.json` 是本项目的中文检索词映射。
